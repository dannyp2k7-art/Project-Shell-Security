 # Projet : ShellSecud – Shell Linux sécurisé en C

Projet réalisé dans le cadre d'un cours au second semestre de l'année universitaire 2025-2026.

## Présentation du projet

Ce projet consiste à développer un shell Linux personnalisé, entièrement recodé en langage C, intégrant les principales commandes et fonctionnalités d'un terminal Linux classique.

Il comprend également un mécanisme de sécurisation du système visant à renforcer sa protection contre les intrusions et les attaques physiques ou réseau.

## Fonctionnalités principales

- Shell Linux personnalisé : implémentation en C des principales commandes et fonctionnalités d'un shell Linux.
- Sécurisation du système : mise en place d'un mécanisme permettant de désactiver par défaut les interfaces et les ports d'entrée afin de limiter les risques d'intrusion.
- Protection des interfaces : désactivation par défaut des connexions Wi-Fi, Bluetooth, USB et des interfaces réseau.
- Réduction de la surface d'attaque : limitation des points d'accès susceptibles d'être exploités lors d'une tentative d'intrusion physique ou réseau.

## Compilation et exécution

Le programme a déjà été compilé à l'aide de GCC (GNU Compiler Collection).

Le fichier exécutable généré est :

bash

```bash
Shellsecud
```

Il constitue le point d'entrée du projet et permet de lancer le shell sécurisé développé en C.

## Objectif du projet

L'objectif est de concevoir un environnement en ligne de commande autonome, combinant les fonctionnalités essentielles d'un shell Linux avec une approche axée sur la sécurité informatique, la réduction de la surface d'attaque et la maîtrise des interfaces de communication du système.
